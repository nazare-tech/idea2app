# Brand

This directory designates the repository as the owner of its brand foundation.

- `brand.md` is the canonical, runtime-neutral source for positioning, voice, messaging, and visual direction.
- `candidates/` holds proposed replacements when a populated foundation must not be overwritten.
- `generated/` holds dated output from optional enhanced brand workflows.

Product, UI, copy, and marketing work should read `brand.md` when it is populated. Paid image or brand-book generation is optional.
