# Task starter — error, empty, and loading states

Load `system-prompt.md` first, then this file.

## Rules

- Say what happened, then what to do. Two sentences maximum.
- Never blame the user. Never say "Oops", "Uh oh", "Something went wrong", or "Please try
  again later" as the whole message.
- Name the recoverable action explicitly, and make it the next thing the user can click.
- Errors use Destructive `#C0392B`, never Action Red. Red is for commitment, not failure.
- Empty states are an invitation to the next action, not an apology for blankness.
- Loading copy states what is being produced, not that work is happening.

## On-voice reference

- Error: "That idea description came through empty. Add a sentence or two about what it does
  and who it is for, then run it again."
- Error: "We could not reach the model. Your draft is saved. Retry when you are ready."
- Empty: "No plans yet. Start with one idea, even a rough one."
- Loading: "Reading the market around your idea." / "Scoping the first version."

## Off-voice, do not produce

- "Oops! Something went wrong 😅"
- "An unexpected error occurred. Error code 500."
- "No data available."
