# Marketing

This file designates this repository as the owner of its marketing captures.

- `ideas/` stores concise source captures and preserves each raw idea verbatim.
- `drafts/` stores developed channel-ready content linked to its source capture.
- `campaigns/` stores multi-asset campaign plans.
- `research/` stores evidence, claim checks, examples, and audience research.

Marketing work should read `brand/brand.md` when it is populated. Nothing in this folder is automatically published, scheduled, uploaded, or sent.
